# Shuyi Wang

Academic homepage: https://yomikoooo.github.io/

This is a static website. Edit `index.html` for content and `style.css` for appearance.

To preview locally:

```sh
python3 -m http.server 8773 --bind 127.0.0.1
```

Then open http://127.0.0.1:8773/.

GitHub Pages publishes the root of the `main` branch. Changes pushed to `main` are deployed automatically.
